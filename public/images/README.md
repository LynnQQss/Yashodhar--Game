# Image assets

The MVP still keeps the lightweight SVG placeholders as fallbacks:

- `rajagaha-bg.svg`
- `nunnery-bg.svg`
- `cave-buddha-bg.svg`
- `yasodhara-portrait.svg`
- `buddha-silhouette.svg`
- `lotus-petal.svg`

Replace them directly, or add JPG/PNG files and update the paths in
`data/chapters.json`. Background images work best at 1920x1080 or wider.
Portraits should use transparent backgrounds.

Current PNG scene assets copied from `bg_picture/`:

reward; the purple low-quality source is preserved but not referenced by the
